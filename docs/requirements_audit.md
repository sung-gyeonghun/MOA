# PRD 요구사항 대조 — 2026-10-13

실제 API 키가 없는 상태에서 검증 가능한 범위와 외부 검증이 필요한 범위를 구분했습니다. 가상 공연의 UI 성공을 실제 전국 데이터 검증으로 간주하지 않습니다.

## 완료로 판정하지 않은 출시 기준

KOPIS 이용 신청·실제 목록/상세/장르별 데이터·콘텐츠 이용 조건, Pages 공개 배포, 실제 Android 기기 검증, 출시 서명과 Play 정책 검토는 아직 완료되지 않았습니다. 서비스키 미발급은 사용자에게 확인받은 외부 선행 조건입니다.

## 산출물

- `dist/moa-preview.apk`: 설치 가능한 R8·리소스 최적화 APK, 개발용 서명

- `docs/verification`: 실제 테스트 XML 및 정적 검사 기록
- `.github/workflows/data.yml`: 준비된 수집·배포 워크플로 (미실행)
- `tools/build-windows.ps1`: 한글 프로젝트 경로용 전용 빌드, `-VerifyDevice`로 Android 테스트 포함
