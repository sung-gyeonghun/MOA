## 산출물

실제 데이터 포함 Preview APK, Debug APK, 미서명 Release APK/AAB, 공개 Pages JSON, GitHub 소스와 데이터 파이프라인, 실제 화면 캡처와 검증 기록.

## 일반 공개 및 출시 전 남은 작업

소유자 정식 서명키, 실제 Android 휴대폰 시험, 일반 공개/Play 정책과 콘텐츠 이용 권한 검토. KOPIS 출처 표시 요구를 반영했지만 모든 포스터의 개별 권리까지 확인한 상태는 아닙니다. Play 출시를 완료했다고 주장하지 않습니다.
