# 모아 개인정보처리방침

시행일: 2026년 10월 13일
운영자: 성경훈
문의: skh1205@naver.com

1. 앱에서 사용하는 정보
모아는 회원가입 없이 공연을 탐색하는 앱입니다. 공연 검색어·최근 검색 기록, 찜한 공연, 선호 지역·장르와 다크모드 설정은 사용자의 기기에 저장됩니다. 공연 목록과 최종 갱신 시각도 오프라인 조회를 위해 기기에 저장됩니다.

이 정보는 앱의 검색·찜·설정 유지에 사용되며, 앱이 운영자에게 전송하거나 계정 간 동기화하지 않습니다. 앱에 광고·분석 SDK는 포함하지 않았습니다. 선택 지역은 사용자가 직접 고르며 GPS 위치를 읽지 않습니다. 연락처·카메라·마이크·광고 ID 접근 권한을 요청하지 않습니다.

2. 인터넷 통신과 외부 서비스
공연 정보를 갱신할 때 GitHub Pages에 공개 데이터 파일을 요청하고, 포스터를 표시할 때 원본 이미지 호스트에 요청합니다. 해당 호스트는 통신에 필요한 IP 주소 등 접속 정보를 자체 정책에 따라 처리할 수 있습니다. 앱은 검색어·찜 목록·선호 설정을 이 요청에 포함하지 않습니다.

공식 예매처를 선택하면 외부 브라우저가 열립니다. 예매·결제 및 해당 사이트의 정보 처리는 예매처의 정책에 따릅니다. KOPIS 인증키는 수집 서버에서 사용하며 앱에 배포하지 않습니다.

3. 저장 기간과 삭제 방법
기기에 저장된 정보는 사용자가 삭제하거나 앱 데이터를 지우거나 앱을 제거할 때까지 유지됩니다. 검색 화면에서 최근 검색어를 삭제할 수 있고, 찜은 하트 버튼으로 해제할 수 있습니다. Android 설정의 모아 앱 저장공간에서 데이터를 삭제하면 목록·찜·검색 기록·선호 설정을 모두 초기화할 수 있습니다. 앱의 Android 자동 백업은 비활성화되어 있습니다.

4. 문의
개인정보 관련 문의는 성경훈(skh1205@naver.com)에게 보내주세요. 이메일 문의에 사용자가 제공한 정보는 문의 응대를 위해 처리됩니다. 앱에는 별도의 문의 수집 폼이나 사용자 계정이 없습니다.

5. 변경 안내
앱의 정보 처리 방식이 변경되면 이 문서와 앱 내 안내를 갱신합니다.
