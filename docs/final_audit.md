## 최신 사용자 변경

메인 별도 로고 삭제·지역 알약 버튼 이동, 두 드롭다운, 지역·장르 복수 선택과 전체 배타 선택, 연월 기간 선택, 흰색 월 선택창과 날짜 칸 정렬, 설정 주소 숨김, 홈 검색창 제거, 키보드 시 하단 메뉴 숨김·복원, 다크모드 저장, README 시각 구성, 하루 1회 갱신, 공개 APK 직접 다운로드 모두 소스·화면·배포 근거가 있다.

## 개발 단계 및 출시 완료 기준

1. 데이터: 사용자 키 발급·실제 인증·전국/장르/상세/포스터/예매 필드 확인. JSON 재배포와 제공 포스터 표시는 사용자가 허용 안내를 확인했다고 직접 답했다.
2. 파이프라인: 저장소·Python·정규화·중복 제거·월별 JSON·검증·수동/예약·Pages 공개 검증 완료.
3. Android: Kotlin Compose·테마·Navigation·Retrofit·목록/상세/검색/필터 구현 완료.
4. 편의: Room 찜·캐시, DataStore 선호·검색·다크모드, 로딩/빈 결과/오류/갱신 시각 완료.
5. 검증/출시 준비: 실제 데이터 확인, 실패 테스트, 사용자 실기기 주요 기능 확인, Release APK/AAB 생성, 공식 Play 정책 검토 및 앱 실제 데이터 처리에 맞춘 개인정보처리방침과 열람 경로 준비.

PRD의 DoD 항목은 기능·예약 갱신·실패 보존·오프라인·실기기·정책 검토 근거로 대조했다. 정식 서명·Play Console 입력/제출은 설치 가능한 Preview와 출시 준비 산출물 이후의 운영자 출시 절차로 남긴다. 이는 Play 출시 완료 주장과 구분된다.
