# 드롭다운·월 단위 기간 변경 검증

2026-10-13 사용자 요청 반영.

- 메인 로고 헤더 삭제, 지역 메뉴를 배너 우측 상단에 배치.
- 장르·기간을 한 줄의 드롭다운으로 변경. 검색 화면도 같은 컴포넌트를 사용.
- 지역 복수 선택과 전국 단독 선택, 장르 복수 선택과 전체 단독 선택. 선택 요약은 필터의 각 메뉴 아래 표시.
- 기존 단일 지역 설정을 복수 지역 설정으로 읽고, 선택한 지역·장르는 DataStore에 저장·복원.
- 이번 달/3개월/6개월은 이번 달 1일에서 해당 마지막 월의 말일까지 조회. 직접 선택은 연·월만 선택.
- 흰색 월 선택창, 연도 이동과 12개월 선택. 시작·종료 월을 세로 배치해 좁은 날짜 칸의 정렬 문제 해결.
- 설정의 공연 데이터·주소 입력 영역 삭제. 내부 데이터 연결 및 메인 하단 수동 새로고침 유지.

근거: Kotlin 필터 테스트 8개, Android 10 연결 테스트 13개 모두 통과. 연도 경계, 시작·종료 월 경계, 공연 기간 겹침, 복수 지역 복원, 연월 직접 선택, 설정 주소 제거 검증. 정적 검사 오류 0개. Preview 설치 후 실제 공연 목록과 흰색 월 선택창을 시각적으로 확인.

화면: `docs/screenshots/home-v2.png`, `filter-v2.png`, `month-picker-v2.png`. 테스트: `month-filter-tests.xml`, `dropdown-month-tests.xml`. APK와 AAB는 `artifacts.json`의 해시로 식별.

직접 선택의 결과는 수집되어 캐시된 공연 범위 안에서 조회된다. UI의 기간 선택만으로 수집 대상 기간이 늘어나지는 않는다.
