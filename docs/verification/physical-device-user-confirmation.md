# 실기기 사용자 확인

2026-10-13 사용자는 실제 휴대폰에서 다음 항목을 모두 확인했고 정상 동작했다고 답했다.

- 공연 검색 및 상세 조회
- 공식 예매 링크를 브라우저로 열기
- 찜 후 앱 종료·재실행 시 유지
- 비행기 모드에서 저장된 목록 조회

근거: 이 대화의 사용자 직접 응답 “모든 항목이 정상 동작했어요”. 당시 공개 배포는 v1.0.1 Preview였다. 사용자가 앞서 실제 휴대폰 메인·필터 화면도 제공했다. 연결된 ADB는 에뮬레이터뿐이며, 기종·OS 버전·성능 계측·스크린 리더 사용 결과는 수집하지 않았다. 에뮬레이터 시험으로 실제 휴대폰 시험을 대체한 기록이 아니다.
